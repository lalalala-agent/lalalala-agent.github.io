傅里叶变换在 CosyVoice3 中的角色，可以概括为一条**“分析—表示—重建”**的链路：音频先经过**短时傅里叶变换（STFT）**被拆解成时间-频率表示，再映射为 Mel 频谱供 Flow Matching 使用；最终 Vocoder 通过**逆短时傅里叶变换（iSTFT）**把频域信息还原回 24 kHz 时域波形。中间的 LLM 处理的是离散语音 Token，不直接涉及傅里叶运算。

下面从公式、图示、各环节参数三个层面完整展开。

## 一、从连续傅里叶变换到 STFT：为什么语音必须“分段”

### 1. 连续傅里叶变换（CFT）

对连续信号 \(x(t)\)，其傅里叶变换定义为：

\[
X(f) = \int_{-\infty}^{\infty} x(t)\, e^{-j2\pi ft}\, dt
\]

逆变换为：

\[
x(t) = \int_{-\infty}^{\infty} X(f)\, e^{j2\pi ft}\, df
\]

物理含义：\(X(f)\) 表示信号中频率 \(f\) 的成分有多强、相位如何。正变换把“随时间变化”翻译成“由哪些频率组成”，逆变换则反过来。

但语音是**非平稳信号**——发音内容在几十毫秒内就会变化。对整段语音做一次 CFT，得到的是全局平均频谱，丢失了时间信息。

### 2. 短时傅里叶变换（STFT）

STFT 用滑动窗把信号切成短帧，每帧近似平稳，再逐帧做傅里叶变换：

\[
\text{STFT}(t, f) = \int_{-\infty}^{\infty} s(\tau)\, h^{*}(\tau - t)\, e^{-j2\pi f\tau}\, d\tau
\]

其中 \(s(\tau)\) 是信号，\(h(\tau - t)\) 是窗函数（如 Hamming 窗），\(*\) 表示复共轭。

**核心权衡**：窗长决定频率分辨率，帧移决定时间分辨率。窗越长，频率分得越细，但时间定位越模糊；窗越短则相反。这一权衡由不确定性原理约束：

\[
\delta t \cdot \delta f \geq \frac{1}{4\pi}
\]

CosyVoice3 的 Mel 参数为 `n_fft=1920`，`hop=480`，采样率 24 kHz。这意味着：

- 每帧覆盖 **1920 个样本 ≈ 80 ms**，频率分辨率约 **12.5 Hz**
- 帧移 **480 个样本 = 20 ms**，即每 20 ms 产生一帧频谱

```
信号:  ████████████████████████████████████████
窗:    [====]
           [====]
                [====]
                     [====]
                          ...
       ├─ hop=480 (20ms) ─┤
```

## 二、从 STFT 到 Mel 频谱：为什么是 80 维

STFT 输出的是**线性频率轴**上的幅度谱。人耳对频率的感知并非线性：1 kHz 以下分辨较细，高频则越来越粗。Mel 刻度模拟这一特性，把线性频率轴压缩为感知更均匀的刻度。

CosyVoice3 的 Flow Matching 输出目标为 **80 维 Mel 频谱**。这 80 个维度对应 80 个 Mel 频带，覆盖 0 到 12 kHz（24 kHz 采样的奈奎斯特上限）。

```
线性频率:  0 ─── 2k ─── 4k ─── 6k ─── 8k ─── 10k ─── 12k (Hz)
           │     │      │      │      │       │       │
Mel 频带:  ████████████████████████████████████████████████
           低频密（分辨细）        高频疏（分辨粗）
           共 80 个频带
```

所以，**一张 Mel 频谱的坐标含义**是：

- **横轴**：时间帧（每帧 20 ms）
- **纵轴**：80 个 Mel 频带（从低频到高频）
- **颜色/数值**：该时刻该频带的能量强度

这就是 Flow Matching 要生成的“中间表示”，也是 Vocoder 的输入。

## 四、Vocoder 端的傅里叶：iSTFT 与谐波源

CosyVoice3 的声码器是 **Causal HiFT**，其底层技术与 HiFTNet 一脉相承。HiFTNet 的核心设计包含两个傅里叶相关的关键组件：

### 1. 逆短时傅里叶变换（iSTFT）

网络不直接逐样本生成波形，而是先预测**短时傅里叶系数**（幅度和相位），再用 iSTFT 把这些频域系数合成为时域波形。这比纯时域卷积更高效，因为频域表示更紧凑。

iSTFT 的公式本质上是 STFT 的逆运算：

\[
s[n] = \sum_{k} \sum_{m} \text{STFT}(m, k)\, h[n - mR]\, e^{j2\pi k n / N}
\]

其中 \(R\) 是帧移，\(N\) 是 FFT 点数。HiFTNet 的消融实验显示，**移除 STFT 模块会导致音质显著下降**（CMOS 降低 0.358），证明频域重建对音质至关重要。

### 2. 谐波-plus-噪声源滤波（频域）

HiFTNet 在时频域引入谐波源：利用预训练的 F0 估计网络得到基频，在频域生成正弦谐波源，再与噪声成分结合。这一设计让声码器在保持轻量的同时达到高质量。

F0 本身对应着语音频谱中**最低的那条谐波轨迹**：

- 成年男性：85–180 Hz
- 成年女性：165–255 Hz
- 这条轨迹在语谱图上就是最下方那条随时间起伏的曲线

## 五、采音端：傅里叶在哪里起作用（以及哪里不起作用）

| 环节 | 是否用傅里叶 | 说明 |
|------|:---:|------|
| 麦克风换能 | ❌ | 声波→模拟电信号 |
| **抗混叠滤波** | ✅ 设计层面 | 必须在 ADC 前滤除 \(f_s/2\) 以上频率，否则采样后混叠无法去除。滤波器设计在频域完成 |
| ADC 采样+量化 | ❌ | 纯时域操作：每 \(1/f_s\) 秒读一个电压值 |
| **重采样（如 48k→24k）** | ✅ | 降采样前必须做低通抗混叠，这是你部署参考音频时最易被忽视的环节 |
| **STFT / 特征提取** | ✅ | 采音后的核心分析工具 |

**关键点**：ADC 采样动作本身不用傅里叶变换，但采样“为什么可行”（奈奎斯特准则）以及采样前的抗混叠设计，都建立在频域分析之上。

## 六、对你 4090 部署的直接含义

| 环节 | 傅里叶相关开销 | 优化方向 |
|------|---------------|---------|
| 参考音频重采样 | 抗混叠滤波（CPU 或 GPU） | 批量预处理，避免推理时重复计算 |
| Flow → Mel | STFT 在训练时用于构造目标；推理时 Flow 直接输出 Mel，不跑 STFT | **Flow 的瓶颈在 DiT 计算，不在傅里叶** |
| Vocoder（HiFT） | iSTFT 是逐帧密集运算 | 分块推理、FP16/BF16；`hop=480` 决定每 20ms 产出一帧音频 |
| 流式 Chunk | 每 20 ms 一个 Mel 帧，WebSocket 按此粒度推送 | 延迟预算 = 帧移 × 流水线缓冲帧数 |

**一个容易被忽略的点**：你部署时如果参考音频是 44.1 kHz 或 48 kHz，**必须先做低通抗混叠再降到 24 kHz**。否则 12 kHz 以上的成分会混叠进可听频段，污染参考音色和 Speech Token，直接降低合成质量。这是采音/预处理链路中傅里叶思想最实际的应用。

---

## 七、一句话总结

> CosyVoice3 的傅里叶变换体现在两端：**STFT 把音频变成 Mel 频谱（Flow 的目标与 Vocoder 的输入）**，**iSTFT 把频域系数还原成 24 kHz 波形（Vocoder 的职责）**。LLM 生成离散 Token 的环节是符号操作，不涉及傅里叶运算。你部署时最需要关注的傅里叶相关细节是：参考音频重采样前的抗混叠滤波，以及 Vocoder 端 iSTFT 的分块推理粒度（hop=480，即 20 ms）。
