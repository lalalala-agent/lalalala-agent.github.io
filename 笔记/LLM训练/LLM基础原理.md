# LLM：基础原理

---

## 一、总览：三个核心问题

理解 LLM 及其衍生模型，重点回答三个问题：

1. **神经网络到底在学习什么？**
2. **Transformer 如何把输入变成有用的表示？**
3. **LLM 如何通过训练学会生成文本？**

这三个问题理解清楚后，再看 Qwen3-VL、VLA 和模型微调，就能把它们放进统一的框架里理解。

### 全局知识地图

```
┌─────────────────────────────────────────────────────────────┐
│  神经网络（学习函数 f_θ）                                    │
│      ↓  用 Transformer 作为骨干网络                          │
│  Transformer（逐层更新 Token 表示）                          │
│      ↓  加上 Tokenizer / Embedding / LM Head                 │
│  LLM（预测下一个 Token）                                     │
│      ↓  改变输入表示与监督目标                               │
│  VLM（+图像）  →  VLA（+图像+机器人状态，输出动作）          │
└─────────────────────────────────────────────────────────────┘
```

## 二、神经网络：本质上是在学习一个函数

### 2.1 函数抽象

神经网络可以抽象为参数化函数：

\[
y = f_\theta(x)
\]

| 符号 | 含义 |
|------|------|
| \(x\) | 输入，例如图像、文本特征或机器人状态 |
| \(y\) | 输出，例如分类结果、下一个 Token 的概率或机器人动作 |
| \(\theta\) | 模型参数，包含各层权重和偏置 |
| \(f_\theta\) | 由多层神经网络计算组成的函数 |

最简单的线性层（以单个样本为例）：

\[
y = Wx + b
\]

**维度变化**：

```
x : (in_dim,)         输入向量
W : (out_dim, in_dim) 权重矩阵
b : (out_dim,)        偏置
─────────────────────────────────
y = Wx + b : (out_dim,)   输出向量

批量形式：
x : (B, in_dim) ──▶ y : (B, out_dim)
```

神经网络通过大量训练样本不断调整 \(W\)、\(b\) 及其他参数，使输出更符合目标。

### 2.2 训练的核心循环

```
        ┌──────────────────────────────────────────┐
        │                                          │
        ▼                                          │
  ┌───────────┐   ┌───────────┐   ┌───────────┐   │
  │ 1. 输入数据│──▶│2. 前向计算 │──▶│ 3. 计算Loss│   │
  └───────────┘   └───────────┘   └───────────┘   │
                                        │          │
                                        ▼          │
                              ┌─────────────────┐  │
                              │4. 反向传播求梯度 │  │
                              │   + 优化器更新   │──┘
                              └─────────────────┘
                                  重复迭代
```

1. **输入数据**：例如一段文本或一张图像
2. **前向计算**：模型根据当前参数计算预测结果
3. **计算 Loss**：衡量预测结果与训练目标的差距
4. **反向传播与参数更新**：计算梯度，并用优化器更新参数

重复以上过程，直到模型在目标任务上学得足够好。

### 2.3 两个关键概念的区别

```
   Loss ──反向传播──▶ 梯度 ∇θ ──优化器──▶ 更新后的 θ
          （算梯度）            （用梯度更新）
```

| 概念 | 作用 |
|------|------|
| **反向传播（Backpropagation）** | 计算每个参数应该如何影响 Loss，即计算梯度 |
| **优化器（Optimizer）** | 根据梯度实际更新参数，例如 SGD 或 AdamW |

> **核心结论**：神经网络不是把正确答案存起来，而是通过训练调整参数，学习输入与输出之间的规律。对于后续的 VLA，这个规律可能是"看到某种场景并收到某个指令时，机器人应该如何行动"。

## 三、Transformer：把输入逐步变成上下文表示

### 3.1 从文本到输入张量

例如输入：

> 机器人拿起杯子，然后把它放到桌子上。

```
文本："机器人 拿起 杯子 ..."
          │
          ▼  Tokenizer
   Token ID: [id_1, id_2, id_3, ...]       形状: (N,)
          │
          ▼  Embedding 查表
   X ∈ ℝ^(N×d)   ← N 个 Token，每个 d 维
          │      批量后: X ∈ ℝ^(B×N×d)
          ▼  （可选）+ 位置编码/位置信息
   X ∈ ℝ^(B×N×d)
```

**关键张量形状**：

| 张量 | 形状 | 说明 |
|------|------|------|
| Token ID | \((B, N)\) | 每个元素是词表索引 |
| Embedding 表 | \((V, d)\) | 可学习参数 |
| 输入表示 \(X\) | \((B, N, d)\) | 每个 Token 一个 \(d\) 维向量 |

### 3.2 Decoder Layer 的两件事（含维度）

**Self-Attention 内部的形状变化**（单头视角，多头见后）：

```
输入 X : (B, N, d)
   │
   ├── W_Q, W_K, W_V 线性映射（各自 d×d）
   ▼
Q = XW_Q : (B, N, d)
K = XW_K : (B, N, d)
V = XW_V : (B, N, d)
   │
   ▼  QKᵀ / √d_k
注意力分数 : (B, N, N)      ← N×N 的注意力矩阵
   │
   ▼  加 Causal Mask + Softmax（沿最后一维）
注意力权重 : (B, N, N)
   │
   ▼  权重 × V
Attention 输出 : (B, N, d)
   │
   ▼  W_O 线性映射
Self-Attention 输出 : (B, N, d)
```

**多头注意力（MHA）**：把 \(d\) 拆成 \(h\) 个头，每头维度 \(d_k = d/h\)。

```
X : (B, N, d)
   │  拆头
   ▼
Q,K,V : (B, h, N, d_k)      每头独立算注意力
   │
   ▼  各头注意力
每头输出 : (B, h, N, d_k)
   │  拼头
   ▼
拼接 : (B, N, d)            h × d_k = d
```

**FFN 内部的形状变化**：先升维到 \(d_{ff}\)（通常是 \(4d\)），再降回 \(d\)。

```
输入 : (B, N, d)
   │  W_1: (d_ff, d)，d_ff 通常 = 4d
   ▼
中间 : (B, N, d_ff)       例：d=4096 → d_ff=16384
   │  激活函数（GELU/SiLU）
   ▼
   │  W_2: (d, d_ff)
   ▼
输出 : (B, N, d)
```

**一个 Decoder Layer 的完整数据流（含维度）**：

```
        X_l  (B, N, d)
          │
          ├──────────────────────┐
          ▼                      │ 残差
   ┌─────────────┐               │
   │ Self-Attention│              │
   │  输出 (B,N,d) │              │
   └─────────────┘               │
          │                      │
          ▼                      │
        (+) ◀────────────────────┘
          │  (B, N, d)
          ▼  Norm
   ┌─────────────┐
   │     FFN      │  d → d_ff → d
   │  输出 (B,N,d) │
   └─────────────┘
          │
          ▼
        (+) ◀── 残差
          │  (B, N, d)
          ▼  Norm
        X_{l+1}  (B, N, d)
```

> **关键观察**：一个 Decoder Layer **输入和输出的形状完全相同**，都是 \((B, N, d)\)。这正是残差连接能成立、以及可以堆叠 \(L\) 层的前提。

经过多层堆叠：

```
X_0 ──▶ Layer1 ──▶ X_1 ──▶ Layer2 ──▶ X_2 ──▶ ... ──▶ LayerL ──▶ X_L
(B,N,d)  (B,N,d)   (B,N,d)  (B,N,d)   (B,N,d)          (B,N,d)  (B,N,d)
```

### 3.3 层级的直观理解

```
浅层  ████░░░░░░░░  基础 Token 关系
中层  ████████░░░░  更复杂的上下文组合
深层  ████████████  有助于预测下一个 Token 的高层表示

（形状始终是 (B, N, d)，变化的是向量里承载的语义信息）
```

| 层级 | 作用（直观概括） |
|------|------------------|
| 浅层 | 学习和处理相对基础的 Token 关系 |
| 中间层 | 组合更复杂的上下文信息 |
| 深层 | 形成有助于预测下一个 Token 的高层表示 |

> 注意：这是帮助理解的概括，不代表每一层都严格对应某种固定语义。

### 3.4 Decoder 为什么需要 Causal Mask？

在标准自回归 LLM 中，预测当前位置时不能看到未来 Token。

```
        Token:  机器人   拿起   杯子   [预测目标]
                  │       │      │
  机器人 可看:    ✓       ✗      ✗
  拿起   可看:    ✓       ✓      ✗
  杯子   可看:    ✓       ✓      ✓
  （✓ 可访问，✗ 被 Mask 屏蔽）

  注意力矩阵 (B, N, N) 示意（上三角被屏蔽为 -∞，Softmax 后为 0）：
        ┌─────────────┐
   机器人│ 1  0  0  0 │
   拿起  │ ✓  1  0  0 │
   杯子  │ ✓  ✓  1  0 │
   目标  │ ✓  ✓  ✓  1 │
        └─────────────┘
```

> Mask 加在 Softmax 之前，形状为 \((B, N, N)\) 或可广播的 \((1, 1, N, N)\)。适用范围说明：这里讨论的是标准自回归 Decoder-only LLM。编码器模型和部分多模态架构的注意力规则可能不同。

## 四、LLM：Decoder 如何变成语言模型？

### 4.1 完整结构抽象（含每层维度）

以一次训练迭代为例（\(B\) 条样本，每条 \(N\) 个 Token）：

```
  文本输入（B 条，每条 N 个 Token）
     │
     ▼
 ┌─────────┐
 │Tokenizer│  文本 ↔ Token ID
 └─────────┘
     │  Token ID : (B, N)        dtype=int
     ▼
 ┌──────────────────────────┐
 │Token Embedding + 位置信息 │  Token ID → 向量
 └──────────────────────────┘
     │  Embedding: (B, N, d)
     │  + 位置信息: (B, N, d) 或位置编码加到 Attention 中
     ▼  X_0 : (B, N, d)
 ┌──────────────────────────┐
 │  Decoder Layer × L        │  每层: (B,N,d) → (B,N,d)
 └──────────────────────────┘
     │  X_L : (B, N, d)
     ▼
 ┌─────────┐
 │ LM Head │  线性层 d → V
 └─────────┘
     │  Logits : (B, N, V)
     ▼
 ┌────────────────────┐
 │Softmax / 解码策略   │  沿最后一维做 Softmax
 └────────────────────┘
     │  概率 : (B, N, V)
     ▼
  每个位置选 Token
```

| 组件 | 输入形状 | 输出形状 | 说明 |
|------|----------|----------|------|
| **Tokenizer** | 文本 | \((B, N)\) | Token ID |
| **Token Embedding** | \((B, N)\) | \((B, N, d)\) | 查表 \(V \times d\) |
| **位置信息** | — | \((B, N, d)\) | 加到 Embedding 上或注入 Attention |
| **Decoder Layer × L** | \((B, N, d)\) | \((B, N, d)\) | 形状不变 |
| **LM Head** | \((B, N, d)\) | \((B, N, V)\) | 线性层 \(d \to V\) |
| **Softmax** | \((B, N, V)\) | \((B, N, V)\) | 沿 \(V\) 维归一化 |

> 说明：LM Head 对**每个位置**都输出一个词表分布，但训练和推理时通常只关心"预测下一个 Token"的位置（见 4.4）。

### 4.2 LLM 的输出是什么？

假设词表有 100,000 个 Token，取**最后一个位置**的隐藏向量：

```
X_L : (B, N, d)
        │  取最后一个位置（或每个位置都要）
        ▼
隐藏向量 h : (B, d)          （只看最后位置时）
        │  LM Head: W ∈ (V, d)
        ▼
Logits z : (B, V)            V = 100,000
        │  Softmax（沿 V 维）
        ▼
概率 P : (B, V)
        │  解码策略（贪心/采样）
        ▼
选出的 Token : (B,)
```

若对**所有位置**都算：

```
Logits : (B, N, V)  →  Softmax  →  (B, N, V)
```

示例（给定"今天天气很"）——以下数字仅用于说明机制，并非真实模型输出：

| 候选 Token | 概率 |
|------------|------|
| 好 | 0.55 |
| 冷 | 0.20 |
| 热 | 0.12 |
| 其他 Token | 0.13 |

> 模型并不是直接输出整段话，而是先预测下一个 Token，再将生成的 Token 加入上下文，继续预测。这就是 **Autoregressive Generation（自回归生成）**。

### 4.3 自回归生成示意

```
"今天天气很" ──▶ 模型 ──▶ "好"
"今天天气很好" ──▶ 模型 ──▶ "，"
"今天天气很好，" ──▶ 模型 ──▶ "适合"
"今天天气很好，适合" ──▶ 模型 ──▶ ...
            （每步把新 Token 拼回输入，循环生成）

形状视角（单条样本，B=1）：
第1步：输入 (1, N)   → Logits (1, N, V)   → 取最后位置 → 选 1 个 Token
第2步：输入 (1, N+1) → Logits (1, N+1, V) → 取最后位置 → 选 1 个 Token
...
（N 每步 +1；实际实现常用 KV Cache 避免重复计算）
```

### 4.4 LLM 是怎么训练出来的？

主流自回归 LLM 的基础预训练目标是 **Next Token Prediction（下一个 Token 预测）**。

假设训练文本是：`机器人 可以 抓取 杯子`

构造的预测任务：

```
输入上下文            预测目标
────────────────────────────────
机器人          ──▶   可以
机器人 可以      ──▶   抓取
机器人 可以 抓取 ──▶   杯子
```

> 实际训练通常会并行计算多个位置的预测，而不需要逐个 Token 单独训练。

```
一次前向，并行预测多个位置：
输入 Token:  [机器人] [可以] [抓取]     形状 (B, N)
                │        │       │
                ▼        ▼       ▼
Logits:        (B, N, V)  ← 每个位置都有 V 维分布
                │        │       │
目标 Token:    [可以]   [抓取]  [杯子]   形状 (B, N)
                │        │       │
                ▼        ▼       ▼
Loss:          L1   +   L2   +  L3   → 总 Loss（标量）
        （对每个位置算交叉熵，再求和/平均）
```

对于目标 Token \(x_t\)，损失函数通常使用交叉熵：

\[
\mathcal{L} = -\sum_t \log P_\theta(x_t \mid x_{<t})
\]

**张量视角**：

| 张量 | 形状 | 说明 |
|------|------|------|
| Logits | \((B, N, V)\) | 每个位置的词表分布 |
| 目标 Token | \((B, N)\) | 每个位置的正确答案 |
| 每位置 Loss | \((B, N)\) | 交叉熵逐位置计算 |
| 总 Loss | 标量 `()` | 求和或平均后用于反向传播 |

含义：
- 正确 Token 的预测概率越高，Loss 越小
- 正确 Token 的预测概率越低，Loss 越大
- 反向传播根据 Loss 计算梯度，再由优化器更新参数

重复大量训练之后，模型会逐步学习语言结构、词语关系、事实关联以及一些可以通过文本训练获得的推理模式。

> **注意**：预测下一个 Token 是训练目标，不等于模型只会机械地续写，也不意味着模型一定掌握了真实世界中的因果规律。

## 五、预训练、SFT 和推理：三个不同阶段

这是后续学习模型微调时必须分清的概念。

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│   预训练      │───▶│     SFT      │───▶│    推理       │
│ Pretraining  │    │ 监督微调      │    │  Inference   │
├──────────────┤    ├──────────────┤    ├──────────────┤
│大量文本       │    │指令+高质量回答│    │固定参数       │
│Next Token预测 │    │学会遵循指令   │    │输入→生成Token │
│参数大幅更新   │    │参数微调       │    │参数不更新     │
└──────────────┘    └──────────────┘    └──────────────┘
   学会"语言"         学会"听话"          实际使用
```

| 阶段 | 目标 | 典型过程 | 维度视角 |
|------|------|----------|----------|
| **预训练（Pretraining）** | 使用大量文本进行下一个 Token 预测，让模型学习通用语言表示和知识 | Next Token Prediction | Logits \((B,N,V)\) vs 目标 \((B,N)\) 算交叉熵 |
| **监督微调（SFT）** | 使用指令和高质量回答训练模型，让它学会按照要求回答问题、遵循指令或调用工具 | 提高目标回答中 Token 的预测概率 | 同样 \((B,N,V)\)，但只在回答位置算 Loss |
| **推理（Inference）** | 固定训练好的参数，输入提示词，逐步生成 Token；一般不会在每次回答时更新模型参数 | 输入 → 前向计算 → 选择 Token → 继续生成 | 每步输入 \((B,N)\)，取最后位置 \((B,V)\) 选 Token |

### SFT 的损失计算范围（含 Mask）

```
样本：[指令/提示词部分] [回答部分]
        │                  │
        ▼                  ▼
    不计算 Loss        计算 Loss  ◀── SFT 常只监督回答部分

形状视角：
  Logits : (B, N, V)
  目标   : (B, N)
  Loss Mask : (B, N)  —— 提示词位置=0，回答位置=1
  有效 Loss = Σ(逐位置 Loss × Mask) / Σ(Mask)
```

> 预训练和 SFT 都可以使用相似的交叉熵损失，但训练数据、监督方式和优化目标侧重点不同。SFT 常常只对回答部分计算损失，而不对全部提示词计算损失。

## 六、把这些原理连接到 VLM 和 VLA

### 6.1 三类模型的结构对比（含维度）

```
【普通 LLM】
  文本 Token (B,N) ──▶ Embedding (B,N,d) ──▶ Decoder (B,N,d)
                    ──▶ LM Head (B,N,V) ──▶ 下一个 Token

【VLM 视觉语言模型】
  图像 (B,3,H,W) ──▶ Vision Encoder ──▶ 视觉特征 (B,N_v,d)
                                          │
  文本 (B,N_t) ──▶ Token Embedding (B,N_t,d)
                                          │
                    拼接/融合: (B, N_v+N_t, d)
                                          │
                    ──▶ LLM Backbone ──▶ LM Head (B,N,V) ──▶ 文本回答

【VLA 视觉语言动作模型】
  图像 (B,3,H,W) ─┐
  指令 (B,N_t)   ─┼──▶ 多模态 Backbone ──▶ 特征 (B,·,d)
  状态 (B,d_s)   ─┘                          │
                                             ▼
                              动作预测模块 ──▶ 动作 (B, T_a, d_a)
```

| 模型类型 | 输入形状 | 核心结构 | 输出形状 |
|----------|----------|----------|----------|
| **普通 LLM** | 文本 \((B,N)\) | Decoder Backbone | \((B,N,V)\) → 下一个 Token |
| **VLM（视觉语言模型）** | 图像 \((B,3,H,W)\) + 文本 \((B,N_t)\) | Vision Encoder + 融合 + LLM Backbone | \((B,N,V)\) 文本回答 |
| **VLA（视觉语言动作模型）** | 图像 + 指令 + 状态 | 多模态 Backbone + 动作预测模块 | \((B,T_a,d_a)\) 动作或动作序列 |

> 符号说明：\(N_v\) = 视觉 Token 数，\(N_t\) = 文本 Token 数，\(d_s\) = 状态维度，\(T_a\) = 动作序列长度，\(d_a\) = 动作维度。各模型具体实现中维度名称可能不同，但"输入扩展、输出改变、骨干形状保持 \((B,N,d)\)"这一规律普遍成立。

> **核心区别**：它们之间最核心的区别不是 Transformer 是否相同，而是**输入表示、输出空间和训练监督目标**发生了变化。
> - LLM：主要学习文本 Token 的预测
> - VLM：引入图像表示，学习视觉与语言之间的关联
> - VLA：进一步学习视觉、语言、机器人状态与动作之间的对应关系

### 6.2 VLA 的训练样本（含维度）

VLA 的训练样本可以表示为：

\[
(I_t, L, s_t) \longrightarrow A_t
\]

```
      输入（多模态）                              输出
┌────────────────────────────┐          ┌──────────────────┐
│ I_t  当前图像 (B,3,H,W)      │          │                  │
│ L    指令 (B,N_t)            │──模型──▶│ A_t 动作 (B,T_a,d_a)│
│ s_t  状态 (B,d_s)            │          │ 或动作序列        │
└────────────────────────────┘          └──────────────────┘
```

| 符号 | 含义 | 典型形状 |
|------|------|----------|
| \(I_t\) | 当前图像 | \((B, 3, H, W)\) |
| \(L\) | 自然语言指令 | \((B, N_t)\) |
| \(s_t\) | 机器人状态 | \((B, d_s)\) |
| \(A_t\) | 目标动作或动作序列 | \((B, T_a, d_a)\) 或 \((B, d_a)\) |

此时，训练损失不一定是文本 Token 的交叉熵，也可能是：
- 动作回归损失（如 MSE，作用于 \((B,T_a,d_a)\)）
- Diffusion 损失
- Flow Matching 损失

> 前面学到的神经网络训练循环仍然成立，只是**预测对象和损失函数变了**。

### 6.3 统一视角：变的只是输入/输出/损失

```
             输入表示          骨干计算        输出空间          损失函数
LLM    │  文本 (B,N)     │  Transformer  │  (B,N,V) 词表分布 │  交叉熵
VLM    │  图像+文本       │  Transformer  │  (B,N,V) 词表分布 │  交叉熵
VLA    │  图像+指令+状态   │  Transformer  │  (B,T_a,d_a) 动作 │  回归/Diffusion/Flow
        └─────────────────┴───────────────┴──────────────────┴──────────┘
              （变化）        （形状不变）      （变化）          （变化）
```

## 七、本阶段需要掌握的结论

1. **神经网络**：通过 Loss、梯度和优化器学习参数化函数。
2. **Transformer**：通过多层 Attention 和 FFN，逐步更新上下文表示；**每层输入输出形状均为 \((B,N,d)\)**，这是可堆叠的关键。
3. **LLM**：通过 LM Head 将隐藏表示 \((B,N,d)\) 映射为词表上的预测分布 \((B,N,V)\)，主流自回归模型使用下一个 Token 预测进行预训练。
4. **微调**：改变训练数据与监督目标（如 SFT 用 Loss Mask 只监督回答部分），让模型适应特定任务。
5. **VLA**：沿用神经网络与 Transformer 的基本计算机制，但把输入扩展到视觉和机器人状态，把输出扩展到机器人动作。
